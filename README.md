# Carousel Studio

A browser-based seamless carousel editor for creating Instagram carousel posts.

## V1 goals

- Instagram portrait canvas (1080×1350 per page)
- 2–10 seamless pages on one continuous workspace
- Upload multiple images
- Drag, resize and rotate elements across page boundaries
- Add and style text
- Background controls
- Add, delete and reorder pages
- Undo / redo
- Preview swipe boundaries
- Save projects locally in the browser
- Export each page as high-quality JPG

## Planned stack

- Next.js
- TypeScript
- Tailwind CSS
- Konva / react-konva
- IndexedDB for local projects
- Client-side image processing and export

The first version is designed to work without accounts or a backend.
